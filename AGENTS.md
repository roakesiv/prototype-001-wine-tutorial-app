# AI Agent Instructions for Wine Tutorial App Repository

## Branch Model
- **main**: Stable, published branch for production-ready code
- **v1-learning-lab**: Experimental branch for prototyping and AI-assisted development

## App Goal
This app helps beginner wine drinkers learn how to taste wine in a low-pressure, playful, and useful way. It reduces intimidation by teaching direct description first, celebrates small wins, and avoids feeling like homework.

## Product Principles
- Tutorial-first, notes-second approach
- Structured learning with clear progression
- Reduce stress through gentle guidance
- Celebrate small successes and progress
- Explain why concepts matter
- Provide optional deeper help when ready
- Prioritize direct description before poetic language
- Use playfulness and silliness as learning reinforcement
- Avoid homework-like feelings

## UX Rules
- Review each screen for emotional feel, visual hierarchy, text density, action clarity
- Ensure progressive disclosure and proper help placement
- Maintain mobile usability and accessibility basics
- Include success/celebration moments
- Control scope to avoid overwhelming users

## Wine-Learning Reference Rules
- Use Wine Folly as the model for beginner accessibility
- Use WSET as the model for structured tasting categories
- Reference source wine journal docs for product philosophy and learning model
- Prioritize direct description before indirect/poetic language
- Avoid broad wine claims without qualification
- Use beginner-friendly simplifications but avoid false absolutes

## Technical Constraints
- Frontend-only prototype using HTML, CSS, and JavaScript
- No backend, database, authentication, or external dependencies
- No build tooling, frameworks, or package managers
- Focus on lightweight, accessible web standards

## Before-Coding Checklist
- [ ] Review current branch and ensure experimental work is on v1-learning-lab
- [ ] Confirm changes align with app goal and product principles
- [ ] Check technical constraints are respected
- [ ] Review relevant design principles and UX rules

- [ ] Consider wine reference rules for any content changes

- [ ] Verify mobile responsiveness
