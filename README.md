# Prototype 01 — Wine Tutorial App

## Overview

This is a beginner-friendly web prototype designed to make wine tasting feel approachable and structured rather than intimidating.

The prototype guides a user through a simple wine tasting flow, allows optional comments at each step, and generates a final technical tasting note.

## Purpose

The purpose of this prototype is twofold:
1. create a small, functioning web app prototype,
2. learn the workflow of planning, building, and shipping a software prototype using AI-assisted development.

## Current MVP

The current prototype includes:
- a guided tasting flow across six steps,
- required selections for each structured step,
- skip options for more advanced tasting dimensions,
- optional comments at each stage,
- a final review step with rating and buy-again input,
- an auto-generated technical tasting note,
- an editable technical note field for practice.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Local files for development
- GitHub for storage and sharing

## Current Scope

Included in this version:
- single-page web app
- beginner-friendly guided flow
- stateful step progression
- validation logic
- generated final note

Out of scope for this version:
- backend
- database
- user accounts
- analytics
- recommendations engine
- production architecture
- advanced design polish
