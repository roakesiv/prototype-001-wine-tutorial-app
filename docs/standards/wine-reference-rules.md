# Wine Reference Rules

## Guidelines for Wine Content and References

- **Use Wine Folly as the model for beginner accessibility**: Follow Madeline Puckette's approach of making wine approachable, fun, and unintimidating for newcomers.

- **Use WSET as the model for structured tasting categories**: Reference the Wine & Spirit Education Trust's systematic approach to tasting notes (appearance, nose, palate, conclusion).

- **Use the source wine journal docs for product philosophy and learning model**: Draw from wine-journal-source.md and wine-reference-source.md for core concepts and teaching approach.

- **Prioritize direct description before indirect/poetic language**: Teach concrete terms (sweet, sour, bitter) before abstract ones (elegant, complex).

- **Do not make broad wine claims without qualification**: Avoid statements like "Riesling is always sweet" - use qualifiers like "Riesling can be sweet" or "Many Rieslings are sweet".

- **Use beginner-friendly simplifications but avoid false absolutes**: Simplify concepts for accessibility, but don't create rules that aren't true (e.g., don't say "red wines are always tannic").
